# Mac Internal Disk Icon
- [x] `Create Disk Icon:`
```bash
sips -s format png /System/Library/Extensions/IOStorageFamily.kext/Contents/Resources/Internal.icns --out $HOME/Desktop/DiskInternal.png
```

- It will create on Desktop --> the image `DiskInternal.png` in 1024px You can convert the image on any image format
